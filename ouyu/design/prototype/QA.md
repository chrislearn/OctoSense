# 草图检查 · 2026-09-17

在 Chromium 中通过页面按钮、下拉框和真实 PNG 下载验证。都是虚构数据的草图交互检查，不代表生产匿名、位置证明与反作弊已实现。

## 当前版本通过

- 顶部没有参与按钮；熟人页没有好友授权、安装状态、保存策略控件。
- 每次默认保存；不保存仅影响本次，下一次重新默认保存。隐藏只影响本条，旧回忆仍可见；可逐条恢复。
- 单人可独立记忆，无双人认证表述或奖励券；双人模拟的现场互认、领券、一次性核销仍走通。
- 相遇次数由当前保存记录推导（含隐藏）；删除全部回忆后归零，联系人仍保留。
- 删除联系人默认保留独立回忆，可勾选同时删回忆；无悬空引用。删空名单、取消删除、重新导入均正常，不影响系统通讯录。
- 成就曲线支持 4 / 8 周，数据表周数一致。隐藏退出成就与分享统计，恢复计入，删除后次数和徽章重新计算；成就口径不含隐藏。
- 分享卡默认不含曲线；可切暖杏 / 夜蓝，曲线可主动开启 / 关闭。检查 canvas 文字不含三个联系人姓名、位置或具体相遇日期。
- 实际下载并保存 900×1200 PNG，见下面的分享图。没有自动发布到社交媒体。
- 9 类普通页面在 320 / 390 / 768 / 1440px 无横向溢出；实际成功奖励页也通过四档宽度检查。桌面 / 手机 / 分享图视觉检查。
- `node --check app.js` 通过，无 JavaScript 异常；请求只含本机文件、data / blob，无外部网络请求。

上一版检查过信息不一致的 3 次上限、等待、过期、定位拒绝、无库存分支；本轮沿用同一模拟校验，不把它当真实防作弊。
