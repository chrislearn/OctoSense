# 02 · 功能与隐私规则

这是新版目标设计，**不表示当前 Rust 应用已实现**。实现差距见 [04](04-octosense-fit.md)。

## A. 发布

- 一周内任一天（含当天 / 明天），上午 / 下午 / 晚间，城市区域库中的公共片区与通用意愿。时段不短于 3 小时，区域以 1–2km 起步；稀疏时扩大或停止机会提示。
- 区域库只收 ≥1km 的公共片区（商圈、公园绿地、滨水步道、文化街区、办公园区、校园周边、交通枢纽、大型生活片区），按行政区分组，支持名称 / 别名 / 拼音首字母搜索与「最近去过」。**不收单个楼宇、门店、住宅小区、医院、诊所、学校内部、宗教场所与政府机构**；名称一律用「…一带 / …周边 / …公共街区」的模糊措辞。
- 发布前预览「别人看到的样子」，不显示昵称、头像、账号或发布时间。每人只有一个有效发布，修改覆盖旧值，无外部个人发布详情 / 历史。
- 熟人来自本人本机通讯录或手动添加，无好友申请、双向授权，也不查询或展示对方是否安装、注册或在线。是否参与匿名发布由每个人自己的发布动作决定，不由别人添加联系人决定。
- 服务内部仅对实际存在的有效发布做隐私匹配，不要求两人互存联系方式。不发布的人不会被凭空定位；没有他人发布数据时不给熟人机会，界面不解释具体谁没有参与。
- 无独立参与 / 隐身开关。发布即参与本次匿名机会，撤回 / 到期即退出；普通城市建议与私人回忆无需发布。
- 状态：`草稿 → 已发布 → 到期清除`，随时撤回。退出编辑丢弃草稿。未发布也能记录现场相遇。

## B. 匿名机会

首页合并发布、机会与「我们碰到了」。地图仅为街区插图，无人形点、头像、距离、实时定位、缩放追踪、姓名 / 电话搜索。

固定批次生成（起点：30 分钟），同一时间桶只看固定区域，禁止连续移动中心或开关联系人比较结果。至少 5 位不同有效候选才显示熟人机会；不给人数 / 更新时间 / 单人加入与撤回通知。个人撤回立即停止贡献，但不让外部聚合实时暴露单人变化；阈值不满足时统一退为普通建议。

机会标识不能跨批次追踪同一发布者，后端需限制子集查询、多账号、共谋与差分攻击。阈值只是风险控制，不能承诺绝对无法从现实背景猜测。

## C. 匿名回声

固定「咖啡 / 散步 / 吃饭」选择，区域内受保护的通用意愿，无发送者、接收者、数量、已读或私聊。MVP 无自定义文字、图片、表情组合，防止暗号辨认。回声不生成约见承诺，到期与行程一同清除；稀疏场景不发送熟人回声。

## D. 现场互认

1. **先认出人**：线下认识对方后，各自在本机选择联系人，或输入已知姓名 / 电话。无附近候选、账号存在提示或自动搜人。
2. **普通回忆独立完成**：可直接选择本次保存 / 隐藏 / 不保存，不等另一位操作，不检查安装状态。私人记录不等于经过双人验证，不自动获得奖励。
3. **申请奖励时才建立现场会话**：扫码 / 短码连接临时会话，10 分钟有效，不展示账号身份。提供免安装网页确认入口，对方无需事先安装或建立好友关系；可用已有登录或在现场完成必要身份验证。此网页入口是生产目标，草图只模拟其结果。
4. **独立交叉互认**：A 指认 B，B 指认 A，通过已验证的现场身份交叉校验，不依赖双向通讯录或预先好友绑定。不是两人填同一个名字。电话身份需规范化与认证；姓名只作本机标签，不能仅凭同名领券。联系人无需保存对方账号 / 安装状态映射。
5. **短时同地（定位为前置门槛）**：请求一次定位是**建立现场会话的前置条件** —— 未授权就不建立会话、不进入互认，只能留一条普通回忆。设计起点为 10 分钟内、100–200m 合理误差、结合现场会话；设备端处理，只返回是否满足，不展示对方坐标。已授权但同地不成立时，相遇仍可成立，明确说明没有相遇礼的原因。券不分「同地券 / 非同地券」：走完确认即有券（限额 / 无库存除外），走不完就只有普通回忆。
6. **成功**：显示本机称呼，不加载对方资料。各自领券、各自决定本次回忆如何处理，不产生永久好友授权。

状态：`开始 → 定位门槛 → 会话建立 → 本人提交 → 等待双方 → 互认 / 同地校验 → 成功 / 不符合 / 过期 / 取消 / 无券`。

这是**服务内部状态机，不是用户界面**。用户可见的只有四个状态：选人 → 定位门槛 → 等待确认 → 结果。会话短码、本人提交、重试次数等一律不出现在正常路径上；模拟入口收在设置的开发者选项里。见 [../docs/02-redesign-plan.md](../docs/02-redesign-plan.md)。

定位、姓名 / 电话都不足以证明真人见面。真实上线须另设计可验证同地协议、设备可信度、限频与作弊策略；隐私与证明可信度需专门评审。HTML 全是模拟，无真实定位 / 通讯录 / 输入。

原始通讯录不上传，电话不做易枚举的普通哈希。可评估 PSI / OPRF 进行隐私联系人发现，但这是未实现、未证明的方向。会话内受控互认，最多 3 次尝试，另设账号 / 设备 / 关系限频。失败统一提示「双方信息尚未一致」，不揭示谁填了谁或账号存在性。

| 异常 | 下一步 |
|---|---|
| 对方未提交 | 等待另一位现场确认，10 分钟有效；可取消，无在线 / 已读状态 |
| 信息不一致 | 各自检查自己的联系人再试，不回显对方输入 |
| 未授权定位 | 不建立会话；开启定位后重试，或只留普通回忆。不持续索取权限 |
| 已授权但同地不成立 | 相遇仍成立，明说「当时你们不在同一个地方」，不领相遇礼，不谎称验证失败 |
| 过期 / 离场 | 结束会话，可重新现场发起；不自动生成奖励或回忆 |
| 同地成立但奖励限额 / 无库存 | 相遇仍成功，明确无券原因；不能谎称验证失败 |
| 有人取消 | 结束会话，不扣分，不揭示谁取消 |

## E. 相遇礼

- 互认与同地有效后，才可领附近大额餐饮券。样例「双人满 ¥120 减 ¥60」非现金、非无门槛；金额、门槛、适用店、有效期、限新客条件同屏。
- 推荐最多 3 家公共店铺，基于本人主动选择的区域；赞助标「商户赞助」。允许「不消费，直接结束」，商户不可购买好友行程或追踪指定人。
- 每对联系人 7 天最多 1 次赞助礼，另设账号日上限 / 预算；普通回忆不限次。防重关系键仍属关系数据，留存另行解释。
- 每人独立领券，不共享对方领取状态。商户只收一次性核销令牌与规则，核销幂等、防重放；不能查对应联系人、关系或坐标。
- 草图的商户、库存、金额全为虚构。真实活动需约定库存、退款、过期与异常核销客服。

## F. 每次相遇选择，熟人页管理既有数据

每次确认默认选 **保存本次**，也可选隐藏本次 / 不保存本次。选择只影响这一次，下次重新询问，联系人上没有永久策略或保存下拉框。

结束或离开成功页时按本次选择写入；现场流程取消不写入。成功后第一次离页已完成写入，回到成功页不再重复保存或修改原选择，已有记录在回忆页管理。

| 本次选择 / 操作 | 本次回忆 | 旧回忆与下一次 |
|---|---|---|
| 保存 | 只存联系人与日期 | 不改变旧记录；下一次仍独立选择 |
| 隐藏 | 保存且隐藏，只影响此条 | 不连带隐藏同联系人旧记录；可逐条恢复 |
| 不保存 | 不写入，也不累计次数 | 不删除旧记录，不延续为下次策略 |
| 删除单条 / 联系人全部回忆 | 删除正文、备注、缓存、索引和相应计数 | 保留联系人；不改变未来选择 |
| 删除联系人 | 从应用熟人列表移除 | 默认保留独立回忆，可勾选同时删除；不改系统通讯录 |

熟人页显示本机姓名、备注、相遇次数、查看回忆、删除全部回忆、删除联系人。无需查看安装 / 注册 / 授权 / 在线状态，无附近、亲密度或实时活动。

**次数口径**：统计目前保存的相遇记录，含隐藏；不保存不累计，删除后减少 / 归零。不额外保留一份无法删除的终身计数，界面清楚标注此口径。删除联系人而保留回忆时，回忆用当时本机称呼独立展示，重新导入同一联系人后可关联已保留记录。

隐藏记录不进入提醒、搜索、AI 或推荐；保存记录也不自动进行关系评分或 AI 学习。默认无地点、精确时刻、照片、券 ID、旧行程，用户可自愿写备注。

个人成就与频率曲线只统计未隐藏、仍保存的回忆，删除 / 隐藏后重新计算，无独立终身计数。本人可主动生成分享图片，默认无联系人、地点、具体日期与频率曲线；见 [06](06-achievements-sharing.md)。

隐藏不是加密或删除；解锁后的隐藏管理仍可看。两人策略独立：删我这里不删除对方日记，也无法阻止现实记忆、截图或自行记录。删除面板必须解释对方副本和奖励风控例外。

## G. 数据边界与期限（生产目标）

| 数据 | 存放 / 可见 | 清除 |
|---|---|---|
| 草稿 | 本机内存 | 退出编辑 / 应用即丢弃 |
| 粗区域 / 时段 | 匹配服务短期存储，外部只聚合 | 到期立即退出匹配；在线存储 / 缓存 1 小时内物理清除，失败告警。短期存储不入持久备份，独立密钥按期销毁 |
| 精确坐标 | 设备短时处理 | 完成 / 取消立即丢弃，不入日志或 AI；如协议必须后端参与，需另行说明处理范围 |
| 原始互认输入 / 临时令牌 | 本机与验证服务 | 会话结束清除，未完成最多 10 分钟，不入日志 |
| 同地证明 / 会话 | 短期验证服务 | 验证结束去除身份输入 / 位置载荷；去重令牌最长 24 小时 |
| 奖励防重关系键 | 独立受控奖励服务，商户不可查关系 | 最长 7 天 + 24 小时处理窗口 |
| 匿名发放 / 核销令牌 | 奖励服务 | 券最长 7 天有效，到期后 24 小时清除；如真实账务需额外保留义务，上线前另定，不复用行程 |
| 私人回忆 | 本机 | 到本人删除；不默认云同步 / 应用云备份，需说明设备级备份风险 |
| 联系人标签 / 私密匹配输入 | 标签留本机，不保留安装状态，服务端必要输入受保护 | 删除联系人后不再用其做熟人匹配，本机历史按删除选择另处理 |

「历史不保存」指行程和位置历史；默认保存的私人回忆与限期奖励风控是明确例外。不能宣传所有数据即焚。生产清除需覆盖缓存、遥测、崩溃日志、导出与备份；刷新 HTML 不代表已完成生产清除。

## H. AI 与数据模型

AI 只做通用活动建议 / 本人主动提供的文案，不能用 `who_is_free`、`suggest_meetup`、`draft_invite` 输出姓名与行程绑定，不能读隐藏记录。目标用 `get_area_opportunities` 和 `suggest_activity` 替代具名查人。发布、互认、领奖由本人操作，不能代签。

```text
ContactLocal { local_id, label, private_identity_input? } // 无授权、安装状态、永久回忆策略
AvailabilityEphemeral { owner_internal, coarse_area, time_bucket, intent, expires_at }
OpportunityAggregate { batch_id, area, time_bucket, generic_intents, expires_at }
RecognitionSession { nonce, expires_at, self_claim?, reciprocal_valid, co_presence_valid, memory_choice }
RewardClaim { single_use_token, offer_id, expires_at, status } // 无联系人、坐标
EncounterLocal { id, contact_local_id?, local_label_snapshot, date, hidden, optional_note } // 无行程、券 ID
RewardDedupe { rotating_pair_key, expires_at } // 独立受控
```

内部账号标识不可进入发现 DOM、分享链接或 AI 输出。互认输入不持久化。换机 / 多设备同步不是 MVP；以后加入须防止恢复已删除回忆。
