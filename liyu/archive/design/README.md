2026-09-17 新版目标设计。Phase 1 已按该设计落地 `apps/ouyu`（匿名机会发布与回声、现场互认与相遇礼券、熟人计数与删除、回忆正常/隐藏管理、新色板五页侧栏；发布与回声为内存态到期清除）。Phase 2 已落地：成就页（4/8 周频率曲线、每周数据表、三个里程碑，只计可见回忆）、分享卡（暖杏/夜蓝双样式预览、可选频率曲线、保存为 SVG）、匿名 AI 工具（`get_area_opportunities` / `suggest_activity`，结构上不含姓名/人数/联系方式）。待做：真实匹配与同地/防重后端。HTML 全为虚构模拟，不请求定位、相机或通讯录，不持久化数据；不能作为匿名协议和奖励验证已落地的证据。

草图新增「成就」导航与分享卡，支持最近 4 / 8 周曲线、里程碑、暖杏 / 夜蓝样式与 PNG 保存。分享默认不包含频率曲线或他人信息，预览后自行发到社交媒体。

重要调整：具名地图改成匿名机会；无双向授权、安装查询或右上角参与开关；行程到期清除；回忆每次独立选保存 / 隐藏 / 不保存；熟人页显示已保存相遇次数、删除联系人 / 回忆；大额券在真实互认与同地通过后发放，目标支持免安装网页确认；小圈场景优先隐私，回退普通城市建议。
