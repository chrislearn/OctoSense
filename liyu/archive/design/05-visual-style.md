# 05 · 视觉与交互

## 夜色城市里，一次暖的相遇

继承 OctoSense 深蓝背景，用暖杏色表示可能、薄荷绿表示通过。主视觉是公共街区、河流、公园与匿名机会光圈；不画人物、头像、实时坐标或准确距离。区域插图不是实时地图。

| 语义 | 草图值 | 正式映射 |
|---|---|---|
| 页面底 | `#0b1220` | `theme.color_bg_app` |
| 卡片底 | `#111c2c` | container token，草图略提亮 |
| 正文 / 次文 | `#e7edf8` / `#a4b2c9` | text / 对比度验证后的 secondary |
| 操作蓝 | `#82b5ff` | focus token，落地须检查按钮对比度 |
| 机会暖色 | `#ffca91` | 偶遇自有色 |
| 成功绿 | `#9be2bf` | 成功态 |
| 错误 | `#ff9eab` | 文字 + 图标，不只靠颜色 |

## 层级与布局

- 标题 24 / 18 / 15px，正文 14.5px，次文 13px，徽章 11px；中文段落行距 1.35。隐私与券门槛必须能读，放弃旧版 11px 正文。
- 桌面侧栏 208px，内容最大 1240px，右列解释当页边界与下一步。手机 760px 以下单列、底部四导航、安全区留白，320px 不横向溢出。
- 卡片圆角 20px、按钮 12px，触控目标至少 44px；主动作一个，取消和撤回清楚可达。
- 金额、门槛、赞助、有效期同屏，券的未领 / 已领 / 已用用文字说明。

## 交互规范

键盘焦点明显、字段有 label、状态 live region、原生 dialog 支持 Escape 与焦点回收。切页更新选中态与标题；可点卡片使用 button，不以 div 假装控件。

发布预览不出现本机姓名；联系人身份不进入机会区域。互认只显示会话 / 本人提交 / 校验进度，不回显对方输入。

右上角不设参与按钮。熟人行仅有本机称呼、已保存相遇次数、查看 / 删除操作，不显示授权、安装状态或保存策略。保存 / 隐藏 / 不保存用本次确认页的三个选择按钮表达；回忆可逐条隐藏和恢复。

成就页用暖色单线、零基线和每周次数，图表有文本替代与数据表。徽章有已点亮 / 等自然发生文字，无排名。分享图为 3:4 暖杏或夜蓝海报，数字 / 文案清楚，默认不含曲线，预览与保存操作分开。

不用脉冲暗示有人移动。仅短淡入 / hover，尊重 `prefers-reduced-motion`。趣味来自小签、真实见面与回忆，不做连胜、排名、错过惩罚或倒计时恐吓。

系统中文字体、纯 CSS 街区插图，无远程字体、图库、分析 SDK 或外部请求。Makepad 落地延续信息层级，不要求浏览器像素级照搬。
