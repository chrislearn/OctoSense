# 03 · 页面与可点击草图

打开 [prototype/index.html](prototype/index.html)，无需依赖或联网。所有人名、区域、优惠与验证均虚构；状态只在内存，刷新重置。不调用 GPS、相机、通讯录或浏览器存储。

## 信息架构

主导航「发现 / 相遇 / 熟人 / 回忆 / 我」（「我」承载成就、分享、我的券、设置与隐私）。首页合并发布与机会，避免时间、地图、结伴来回切换。发布、互认、领券与分享作为流程页；隐私说明随时可达。桌面侧栏 + 内容 + 解释列，手机底部导航。

| 页面 | 要解决的问题 | 动作 |
|---|---|---|
| 发现 | 怎样给今天留一点可能？ | 发布、撤回、我们碰到了；无右上角参与按钮 |
| 发布 | 我愿意透露多少？ | 粗区域 / 时段 / 意愿，先预览再发布，取消丢弃 |
| 回声 | 有什么顺路的理由？ | 通用活动选择、城市小签，不显示个人响应 |
| 互认 | 真遇到了，如何确认？ | 本机选联系人、选择本次回忆；独立记忆或进入奖励现场会话 |
| 相遇礼 | 附近有何优惠？ | 看门槛、领个人券、模拟核销、不消费、回忆策略 |
| 熟人 | 怎样管理我的熟人？ | 已保存相遇次数、查看回忆、删除全部回忆、删除联系人；无安装 / 授权 / 策略 |
| 回忆 | 留下什么、删掉什么？ | 正常 / 隐藏列表，逐条隐藏、恢复、删除；按联系人筛选 |
| 隐私 | 匿名与删除保证到哪？ | 行程 / 回忆 / 风控边界与限制 |
| 成就 | 我记住了哪些生活里的偶然？ | 可见相遇摘要、4 / 8 周曲线、里程碑、生成分享卡 |
| 分享卡 | 怎样分享而不带出别人的信息？ | 汇总预览、选样式、可选曲线、保存 PNG、自行发布 |

## 可走通的路径

1. 发现 → 发布 → 匿名机会 → 咖啡回声 → 现场碰到 → 选林舟 → 模拟建立会话 → 本人确认 → 模拟对方确认 → 领券 / 核销 → 回忆。
2. 发现切「稀疏场景」→ 不显示熟人机会 → 城市小签 → 仍能现场确认；不会回退显示单个熟人。
3. 互认模拟信息不一致、定位未授权、未确认、过期、无库存，分别重试 / 普通回忆 / 退出，不能伪装成功领券。
4. 本次选隐藏 → 本次只在隐藏管理可见，旧回忆不受影响 → 可恢复 / 删除；下次独立选择。
5. 本次选不保存 → 不新增回忆和次数 → 下一次恢复默认保存，不永久改变联系人。
6. 熟人 → 删除全部回忆 → 次数归零但联系人保留；删除联系人可勾选同时删回忆，默认保留回忆且能继续管理。
7. 撤回 → 熟人机会消失；重新发布才恢复。不检查安装状态、不需要好友批准。行程与回声不进入回忆。

## 关键文案

- 「有机会，不代表一定遇见」，不用「附近有 3 个好友」。
- 「这里不会告诉你是谁」，紧邻机会卡，不藏到设置。
- 「先在线下认出彼此，再各自确认」，不用「看看附近是谁」。
- 「等待另一位现场确认」，无头像、在线状态或对方输入回显。
- 「隐藏本次仍会保存，可逐条恢复」与「不保存只影响这次，旧记录不受影响」分别说明。
- 「商户赞助 · 双人满 ¥120 减 ¥60」，门槛和金额同屏。

## 范围

HTML 有 10 类页面、响应式布局、发布 / 撤回、稀疏回退、活动回声、独立回忆 / 双人确认模拟、券领取 / 核销、单次回忆选择、联系人计数与删除面板、成就曲线与分享图导出。演示工具条不是正式产品的一部分。

HTML 不实现匿名协议、身份映射、位置证明与反作弊。刷新丢失状态只是草图行为，不能当作生产隐私实现的证明。
