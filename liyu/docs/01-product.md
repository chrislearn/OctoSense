# 01 · 产品：匿名悬念送礼

## 一句话

**把「送礼」变成一个小游戏**：礼物先藏起来，TA 得先猜出是谁送的；
礼物背后还可以挂一句小约定，让这份礼有个「下文」。

## 为什么是它

轻社交礼物（一杯咖啡、一张电影票、一只盲盒）价格低、决策快，但直接送有两个尴尬：

1. **太直白**：没有由头，「突然送你杯咖啡」显得用力；
2. **送不准**：送的东西对方未必喜欢，最后躺在抽屉里。

礼遇的解法：

- **悬念**给了由头 —— 「猜我是谁」本身就是一个可以聊起来的话题；
- **契约**给了下文 —— 礼物是开头，「下周请我喝一杯」才是正文；
- **换购 / 折现**解决送不准 —— 不喜欢就换一份，或者变成余额，礼物价值不浪费。

## 角色

| 角色 | 在礼遇里做什么 | 关心什么 |
| --- | --- | --- |
| 送礼人 | 挑礼物、出题、绑契约、发礼卡、看进度 | 对方有没有猜到我；有没有收下；契约会不会兑现 |
| 收礼人 | 拆礼卡、解谜、揭晓、收下 / 换购 / 折现、回礼 | 是谁送的；礼物喜不喜欢；契约是什么、能不能拒绝 |
| 平台 | 提供礼物目录、托管资金、收手续费 | 换购 / 折现手续费、供应链差价、回礼带来的新订单 |

同一个人通常两个角色都有：礼遇的「礼盒」页把**收到的**和**送出的**放在一起。

## 核心循环

```
挑选礼物 → 设置悬念与契约 → 匿名发送 → 收礼人解谜 → 揭晓
                                              ├─ 满意收下（同意契约 + 填地址 / 领电子券）→ 履约
                                              └─ 不太喜欢 → 换购（多退少补）/ 折现（扣手续费）
                                                               └─ 「用这笔余额，给 TA 回一份反击礼物」→ 回到开头
```

循环的关键在最后一步：**折现 / 换购不是流失，而是下一单的起点**。
收礼人手里多了一笔只能在礼遇里用的余额，最自然的用法就是给送礼人回一份。

## 玩法要素

### 1. 礼物（轻社交品类）

| 品类 | 例子 | 形态 |
| --- | --- | --- |
| 咖啡茶饮 | 精品咖啡礼盒、拿铁电子券、奶茶兑换券 | 实物 / 电子券 |
| 电影演出 | 电影通兑票、双人套票 | 电子券 |
| 潮流小物 | 帆布包、香薰蜡烛、拍立得相纸 | 实物 |
| 盲盒 | 潮玩盲盒、文具盲盒 | 实物 |
| 甜点鲜花 | 蛋糕兑换券、同城花束 | 电子券 / 实物 |

价格带控制在 ¥29–¥128：够表达心意，又不至于让收礼人有负担。
**实物**收下时要填地址，**电子券**收下即发券码，不需要地址。

### 2. 悬念（解锁条件）

| 玩法 | 送礼人设置 | 收礼人要做的 |
| --- | --- | --- |
| 猜我是谁 | 一句线索（「上周一起淋雨的那个人」） | 从候选人里选 / 直接输入名字，3 次机会 |
| 专属私密问答 | 一个问题 + 答案 | 输入答案，3 次机会 |
| 专属暗号 | 一句暗号 + 可选提示 | 输入暗号，3 次机会 |
| 无条件直接领取 | 无 | 直接拆开，送礼人署名可见 |

**猜错礼物也不会消失**：3 次用完，礼物照样拆开，只是 TA 的名字继续保密。
这样悬念是加分项，而不是门槛。

### 3. 社交契约（可选）

预设几句轻约定，也可以自定义（≤ 24 字）：

- 下周找时间回请我喝一杯咖啡
- 收下要发一条朋友圈晒一晒
- 周末陪我看一场电影
- 下次见面先给我一个拥抱

契约**不是合同**：没有金钱义务、不能写转账借钱类内容；收礼人可以不同意 ——
不同意就走换购 / 折现，契约随礼物一起作废。同意之后，契约进入双方的「契约」页，
7 天内可标记兑现。

### 4. 神秘礼卡

发送后生成一张礼卡：口令（如 `LY-7K3Q`）+ 链接（`liyu://g/LY-7K3Q`）+ 可保存的礼卡图片。
礼卡上**只有**玩法和线索，没有礼物名、价格、送礼人 —— 悬念留到拆开那一刻。

## 商业化

1. **换购 / 折现手续费**（5%–10% 区间内取值）：
   - 换购 5%：鼓励留在平台内换一份，顺带带来供应链差价；
   - 折现 8%：变成余额的便利要付一点成本；
   - 都向上取整到元、最低 ¥1，页面上**先算给你看**再确认。
   例：¥109 的礼物折现 → 手续费 ¥9，退回 ¥100 余额。
2. **供应链差价**：礼物目录由平台集采，售价与采购价之间的差价（演示里不体现具体数字）。
3. **余额沉淀**：余额只能在礼遇内送礼 / 换购，暂不支持提现 ——
   既是闭环（不需要支付牌照），也天然推动回礼。

## 传播

- 礼卡本身就是传播物：收到礼卡的人不装应用也能打开（演示里用口令模拟）；
- 折现 / 换购完成页的回礼提示：「用刚才变现的 ¥100，给 TA 回送一份『反击礼物』吧！」，
  一键进入送礼流程，收礼人自动填好；
- 契约兑现是线下见面的理由，线下见面又是下一次送礼的由头。

## 非目标（这一版明确不做）

- 真实支付、真实物流、真实提现 —— 全部本地模拟，页面上标注「模拟支付」；
- 陌生人送礼、礼物广场、排行榜 —— 只在熟人之间；
- 把契约做成有约束力的承诺（违约惩罚、信用分）—— 契约是玩笑式的社交约定；
- 让 AI 替人送礼、替人解谜 —— AI 只能查目录、给建议、看汇总。
