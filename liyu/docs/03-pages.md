# 03 · 页面与交互

## 信息架构

```
礼遇
├─ 挑礼（Tab）        [挑礼物] 品类芯片 + 商品宫格          顶栏：发起神秘送礼
│                     [熟人的心愿单] 我的心愿单入口 + 好友心愿单卡片   顶栏：发布心愿单
├─ 礼盒（Tab）        收到的 / 送出的                      顶栏：发起神秘送礼
├─ 契约（Tab）        我答应的 / 答应我的
├─ 熟人（Tab）        熟人列表，「送礼」/「看心愿单」       顶栏 +：添加 / 导入
└─ 我（Tab）          余额卡 + 统计 + 入口
     ├─ 我的心愿单
     ├─ 钱包与流水
     ├─ 设置（外观 / 我的称呼 / 通知 / 数据）
     └─ 关于（重看引导）

覆盖页（盖在 Tab 之上，顶栏出现「‹ 返回」）
├─ 商品详情    page_product     大图 + 信息 + 介绍 + 同类还有
├─ 送礼页      page_send        单页表单，底部固定「合计 + 去结算」
├─ 结算页      page_checkout    确认订单 → 付款 → 原地变成「支付成功」
├─ 礼卡页      page_card        付款成功后的礼卡
├─ 拆礼页      page_open        解密 → 揭晓 → 收下 / 换购折现 → 完成（同一页换内容）
├─ 送出详情    page_sent        进度时间线 + 撤回 + 演示模拟
├─ 我的心愿单  page_wishes      我发布过的心愿单卡片 + 发布一张
├─ 心愿单详情  page_wish        我的 / 好友的共用一页，按钮不同
├─ 发布心愿单  page_wish_edit   发布和编辑共用
└─ 挑一件      page_wish_pick   放进心愿单（全目录）/ 帮 TA 挑（符合的候选）共用
```

覆盖页的返回规则：商品详情、送礼页、结算页和四个心愿单页面有**返回栈**，
「‹ 返回」一层层退回来路（例：好友心愿单 → 帮 TA 挑 → 商品详情 → 送礼页 → 结算），
栈空了回到进来的 Tab；付款成功后栈清空。拆礼页 / 送出详情 → 礼盒；礼卡页「完成」→ 礼盒·送出的；
钱包 / 设置 → 我。切 Tab 一律清栈。首次启动先看 3 屏引导（page_intro）。

## 通用规则

- **响应式**沿用原壳：手机 < 720（底部 Tab 栏）、平板、桌面 ≥ 1060（左侧栏）；
  ≥ 900 时列表页右侧显示辅助栏（aside），手机上辅助栏内容折叠到列表下方或省略。
- **空状态**：每个列表都有 LiyuEmpty（一句话 + 一个动作按钮）。
- **toast**：底部居中 2.4 秒；删除类操作带「撤销」。
- **金额**：整元显示 ¥109；有角分时 ¥9.50。余额恒显示两位小数以外的整数形式（演示金额都是整元）。
- **文案口吻**：轻松、不说教；不用 emoji（字体不稳），用 svg 小图标。
- **商品图**：每件商品一张 400×400 圆角示意图（`apps/liyu/resources/products/pNN.png`，编号 = 目录下标），
  未揭晓的礼物用问号礼盒图 `mystery.png`。凡是出现商品的地方都带图：宫格、详情、送礼页、结算、
  礼盒行、礼物卡、换购列表、送出详情、心愿单。图第一次用到才解码，之后复用。
- **商品宫格**（挑礼、同类还有、挑一件共用 `LiyuProductCard`）：卡 = 方图 + 名称（一行省略）+ 品牌 +
  可选一行蓝字理由 + ¥价格 · 形态。列数按正文宽度算：`floor((宽 + 12) / 162)`，限制在 2–5 列，
  卡宽均分，所以手机上两列、桌面四到五列。

- 已选礼物卡：左图右文，名称可以换行，价格单独一行暖色大字，「换一件」在标题行右侧；
- 「换一件」展开一个小列表（最多 12 行，带缩略图）：平时是同品类换，按钮叫「同类换一件」；
  认领「说个大概」的心愿时只在符合的候选里换，叫「换一件符合的」；认领具体的心愿时隐藏；
- 认领心愿时收礼人固定为主人：芯片收起，换成一行「林舟（心愿单的主人）」；
- 「什么时候送到」默认约在那天（从心愿单进来时就选好），可改成「现在就送」；
- 解锁方式四个分段，切换时只显示对应输入框；
- 契约开关关闭时芯片和自定义框隐藏；点芯片把文字填进自定义框（可再改）；
- 底栏固定：只写合计和余额最多能抵多少 + 「去结算」。怎么付在结算页里选；
- 校验（点「去结算」时，和结算页付款前是同一套）：
  - 猜我是谁：线索必填；
  - 私密问答：问题、答案必填；
  - 专属暗号：暗号必填；
  - 契约：开启时不能为空、≤ 24 字、不含禁用词（见 04-rules）；
  - 寄语 ≤ 40 字；
  - 心愿还能不能认领（见 04-rules 心愿单）；
  - 错误显示在按钮上方一行红字（一次只显示第一条），并 toast；
- 回礼进入时：「送给谁」已选好，顶部蓝条「回礼 · 刚变现的 ¥100 可用」。

- 付款成功后返回栈清空：「‹ 返回」回到进来的 Tab，不会退回已经付过的结算页。

## 7. 拆礼页（page_open）

一个页面四个阶段，顶部标题随阶段变：「神秘礼物」「礼物揭晓」「收下礼物」「换购 / 折现」。

### 7.1 解密

```
│        你收到一份神秘礼物                      │
│        [猜我是谁]                         │
│ ┌ TA 留下的线索 ───────────────────────────┐ │
│ │ 上周一起淋雨的那个人                         │ │
│ └──────────────────────────────────────────┘ │
│ 可能是：[林舟] [陈晓] [许宁] [周子墨] [林小满] [黄一诺] │
│ [输入 TA 的名字____________]                   │
│ 剩余 3 次机会              [提交答案]            │
│ 猜错了礼物也不会消失哦                           │
```

- 点候选芯片 = 填入输入框（不直接提交）；
- 私密问答：卡片标题「TA 的问题」，无候选芯片；专属暗号：卡片标题「暗号提示」，
  无提示时写「TA 说：你知道的」；演示数据里暗号礼物附一行灰字「演示提示：暗号是……」；
- 答错：输入框下方红字「不是 TA，再想想」/「答案不对，再想想」，机会 −1；
- 直接领取的礼物：卡片写「TA 说直接拆就好」，只有一个「拆开礼物」按钮。

```
│ └──────────────────────────────────────────┘ │
│ [✓ 满意，开心收下（同意契约并填地址）]              │
│ [↻ 不太喜欢？换购 / 折现（折现退回 ¥100，手续费 ¥9）] │
```

- 没有契约时契约卡隐藏，收下按钮文字去掉「同意契约」；电子券去掉「填地址」；
- 已经是终态的礼物再打开：揭晓内容 + 顶部一行结果（「你已收下 · 券码 XXXX」等），按钮隐藏。

### 7.3 收下

- 契约开关行「我同意：……」（有契约时必须打开；用开关而不是胶囊，契约长也能换行）；
- 实物：收件人、手机号、地址三个输入框；电子券：说明「收下后立即发放券码」；
- [确认收下] → 完成卡：「收下啦」+ 券码 / 发货说明 + [给 TA 回一份礼] [回礼盒]。

### 7.4 换购 / 折现

- 分段 [折成余额] [换一份]，默认「折成余额」；
- 折成余额：三行算式（价值 / 手续费 8% / 退回余额）+ [确认折现]；
- 换一份：抵扣额一行 + 礼物列表（最多 11 行，排除当前这件），每行右侧「退 ¥x」或「补 ¥y」；
  点选一行高亮，底部算式更新，[确认换购]；补差时说明「余额抵 ¥a · 模拟支付 ¥b」；
- 完成卡：结果一句话 + 回礼提示「用刚才变现的 ¥100，给 TA 回送一份『反击礼物』吧！」
  + [去回礼] [以后再说]（换购完成时提示改为「礼尚往来，给 TA 也回一份吧」）。

## 13. 引导（3 屏）

1. 送一份猜得到的心意 —— 挑一件小礼物，出一道只有 TA 答得上的题；
2. 契约让礼物有下文 —— 「收下就请我喝杯咖啡」，礼物是开头；
3. 不合心意？换购或折现 —— 四条要点：猜错不消失只是名字保密 / 7 天没拆全额退回送礼人 /
   换购 5% 折现 8% 先算给你看 / 余额只在礼遇内使用暂不支持提现。
