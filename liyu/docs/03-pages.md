# 03 · 页面与交互

## 信息架构

```
礼遇
├─ 挑礼（Tab）        品类芯片 + 礼物列表                  顶栏：发起神秘送礼
├─ 礼盒（Tab）        收到的 / 送出的 + 口令打开           顶栏：发起神秘送礼
├─ 契约（Tab）        我答应的 / 答应我的
├─ 熟人（Tab）        熟人列表，「送礼」直达送礼页         顶栏 +：添加 / 导入
└─ 我（Tab）          余额卡 + 统计 + 入口
     ├─ 钱包与流水
     ├─ 设置（外观 / 我的称呼 / 通知 / 数据）
     └─ 关于（重看引导）

覆盖页（盖在 Tab 之上，顶栏出现「‹ 返回」）
├─ 送礼页    page_send      单页向导，底部固定付款条
├─ 礼卡页    page_card      发送成功后的礼卡
├─ 拆礼页    page_open      解密 → 揭晓 → 收下 / 换购折现 → 完成（同一页换内容）
└─ 送出详情  page_sent      进度时间线 + 撤回 + 演示模拟
```

覆盖页的返回规则：拆礼页 / 送出详情 → 礼盒；礼卡页「完成」→ 礼盒·送出的；
送礼页 → 进来的那个 Tab。首次启动先看 3 屏引导（page_intro）。

## 通用规则

- **响应式**沿用原壳：手机 < 720（底部 Tab 栏）、平板、桌面 ≥ 1060（左侧栏）；
  ≥ 900 时列表页右侧显示辅助栏（aside），手机上辅助栏内容折叠到列表下方或省略。
- **空状态**：每个列表都有 LiyuEmpty（一句话 + 一个动作按钮）。
- **toast**：底部居中 2.4 秒；删除类操作带「撤销」。
- **金额**：整元显示 ¥109；有角分时 ¥9.50。余额恒显示两位小数以外的整数形式（演示金额都是整元）。
- **文案口吻**：轻松、不说教；不用 emoji（字体不稳），用 svg 小图标。

- 点一行 → 送礼页并选中这件；顶栏按钮 → 送礼页并默认选第一件。

```
┌ ‹ 返回        发起神秘送礼 ───────────────────────┐
│ ┌ 已选礼物 ───────────────────────────────────┐ │
│ │ [咖] 三顿半精品咖啡礼盒  实物 · 24 颗装  ¥109 │ │
│ │                                   [换一件] │ │
│ └────────────────────────────────────────────┘ │
│ 送给谁（仅自己可见）                                │
│ [林舟] [陈晓] [许宁] [先不指定]                       │
│                                                │
│ 1 · 设置解密游戏                                   │
│ [猜我是谁] [私密问答] [专属暗号] [直接领取]            │
│   线索  [上周一起淋雨的那个人____________]           │
│   TA 要猜的名字：阿岚（在「设置 · 我的称呼」里改）       │
│                                                │
│ 2 · 绑定社交契约（可选）                   [开关]     │
│   [下周回请我喝咖啡] [发朋友圈晒一晒] [陪我看电影] [见面先拥抱] │
│   [自定义契约，最多 24 字________________]          │
│                                                │
│ 3 · 寄语                                         │
│   [写一句话给 TA，最多 40 字______________]         │
│                                                │
├────────────────────────────────────────────────┤
│ 优先用余额抵扣（余额 ¥20）[开关]                      │
│ 余额抵 ¥20 · 模拟支付 ¥89                          │
│ [        生成神秘礼卡并发送（¥109）        ]          │
└────────────────────────────────────────────────┘
```

- 解锁方式四个分段，切换时只显示对应输入框；
- 契约开关关闭时芯片和自定义框隐藏；点芯片把文字填进自定义框（可再改）；
- 校验（点按钮时）：
  - 猜我是谁：线索必填；
  - 私密问答：问题、答案必填；
  - 专属暗号：暗号必填；
  - 契约：开启时不能为空、≤ 24 字、不含禁用词（见 04-rules）；
  - 寄语 ≤ 40 字；
  - 错误显示在按钮上方一行红字（一次只显示第一条），并 toast；
- 回礼进入时：「送给谁」已选好，顶部多一行蓝字「回礼 · 刚变现的 ¥100 可用」。

## 4. 礼盒

```
┌ 礼盒 ────────────────────────────── [发起神秘送礼] ┐
│ [收到的 3] [送出的 2]                              │
│ 口令打开 [LY-____] [打开]                          │
│ ┌──┐ 一份神秘礼物                      待拆       │
│ │? │ 猜我是谁 · 还剩 5 天                         │
│ └──┘                                             │
│ ┌──┐ 电影双人套票 · 陈晓                  已收下    │
│ │影│ 私密问答 · 9月20日                            │
│ └──┘                                             │
└──────────────────────────────────────────────────┘
```

- 收到的：未揭晓的礼物只显示「一份神秘礼物」+ 问号方块；揭晓后显示礼物名 + 送礼人（保密时「神秘的朋友」）；
- 送出的：显示礼物名 + 「送给 林舟」+ 进度状态；
- 状态文字颜色：待处理（待拆 / 解谜中 / 待你决定）蓝，完成（已收下 / 已换购 / 已折现）绿，退回（已过期 / 已撤回）灰；
- 口令框：输入 `LY-XXXX`（大小写、空格、省略 `LY-` 都可）→ 找到收到的礼物则打开拆礼页；找到送出的则打开送出详情；否则 toast「没找到这张礼卡」；
- aside：收到 / 送出统计与「7 天没拆会自动退回」说明。

## 5. 拆礼页（page_open）

一个页面四个阶段，顶部标题随阶段变：「神秘礼物」「礼物揭晓」「收下礼物」「换购 / 折现」。

### 5.1 解密

```
│        你收到一份神秘礼物                      │
│        [猜我是谁]                         │
│ ┌ TA 留下的线索 ───────────────────────────┐ │
│ │ 上周一起淋雨的那个人                         │ │
│ └──────────────────────────────────────────┘ │
│ 可能是：[林舟] [陈晓] [许宁] [周子墨] [林小满] [黄一诺] │
│ [输入 TA 的名字____________]                   │
│ 剩余 3 次机会              [提交答案]            │
│ 猜错了礼物也不会消失哦                           │
```

- 点候选芯片 = 填入输入框（不直接提交）；
- 私密问答：卡片标题「TA 的问题」，无候选芯片；专属暗号：卡片标题「暗号提示」，
  无提示时写「TA 说：你知道的」；演示数据里暗号礼物附一行灰字「演示提示：暗号是……」；
- 答错：输入框下方红字「不是 TA，再想想」/「答案不对，再想想」，机会 −1；
- 直接领取的礼物：卡片写「TA 说直接拆就好」，只有一个「拆开礼物」按钮。

### 5.2 揭晓

```
│  恭喜你答对了！这是 林舟 送你的礼物                │
│ ┌ 礼物卡（暖色券样式）─────────────────────────┐ │
│ │ 三顿半精品咖啡礼盒            价值 ¥109       │ │
│ │ 实物 · 24 颗装                               │ │
│ │ 「降温了，喝点热的」                           │ │
│ └──────────────────────────────────────────┘ │
│ ┌ 附加契约 ─────────────────────────────────┐ │
│ │ 收下表示答应：下周找时间回请我喝一杯咖啡          │ │
│ └──────────────────────────────────────────┘ │
│ [✓ 满意，开心收下（同意契约并填地址）]              │
│ [↻ 不太喜欢？换购 / 折现（折现退回 ¥100，手续费 ¥9）] │
```

- 没有契约时契约卡隐藏，收下按钮文字去掉「同意契约」；电子券去掉「填地址」；
- 已经是终态的礼物再打开：揭晓内容 + 顶部一行结果（「你已收下 · 券码 XXXX」等），按钮隐藏。

### 5.3 收下

- 契约复选框「我同意：……」（有契约时必勾）；
- 实物：收件人、手机号、地址三个输入框；电子券：说明「收下后立即发放券码」；
- [确认收下] → 完成卡：「收下啦」+ 券码 / 发货说明 + [给 TA 回一份礼] [回礼盒]。

### 5.4 换购 / 折现

- 分段 [折成余额] [换一份]，默认「折成余额」；
- 折成余额：三行算式（价值 / 手续费 8% / 退回余额）+ [确认折现]；
- 换一份：抵扣额一行 + 礼物列表（最多 11 行，排除当前这件），每行右侧「退 ¥x」或「补 ¥y」；
  点选一行高亮，底部算式更新，[确认换购]；补差时说明「余额抵 ¥a · 模拟支付 ¥b」；
- 完成卡：结果一句话 + 回礼提示「用刚才变现的 ¥100，给 TA 回送一份『反击礼物』吧！」
  + [去回礼] [以后再说]（换购完成时提示改为「礼尚往来，给 TA 也回一份吧」）。

```
│ 口令 LY-7K3Q  [复制链接]                         │

│  ● 9月23日  TA 打开了礼卡，猜错 1 次              │
│  ○          等 TA 揭晓                         │
│ 玩法：猜我是谁 · 线索「……」                     │
│ 契约：下周找时间回请我喝一杯咖啡                    │
│ [撤回并退款]（仅待拆时）                          │

```

- 时间线最多 5 行（发出 / 打开 / 揭晓 / 结果 / 退回），未发生的用空心点；
- 撤回：确认条「撤回后礼卡失效，¥109 退回余额」→ 确认；
- 模拟按钮：推进一步（规则见 05-data-model），终态后隐藏。

## 7. 契约

```
│ [我答应的 1] [答应我的 1]                        │
│ 下周找时间回请我喝一杯咖啡                          │
│ 答应 林舟 · 9月29日前 · 待兑现        [标记已兑现]  │
│ 周末陪我看一场电影                                │
│ 陈晓 答应我 · 已逾期 1 天          [提醒 TA] [免了吧] │
```

- 我答应的：按钮「标记已兑现」；
- 答应我的：按钮「确认已兑现」「提醒 TA」，次按钮「免了吧」；
- 已兑现 / 已免除的行灰掉并排在最后，无按钮；
- aside：「契约不是合同」三条说明。

## 8. 熟人

保留原熟人页（添加、导入本机 / vCard、删除 + 撤销），改动：

- 行副标题：「送过 2 份 · 收到 1 份」；
- 行按钮：「送礼」→ 送礼页，已选好这位；
- 删掉合并、回忆相关入口。

## 9. 我 / 钱包 / 设置

- **我**：余额大卡（¥x · 「只在礼遇内使用」· [钱包与流水]）、三格统计（送出 / 收到 / 已兑现契约）、
  入口行：钱包与流水、设置、关于（重看引导）；
- **钱包与流水**：余额 + [演示充值 ¥50]；流水列表最多 12 行（标题、日期备注、±金额，入账绿出账默认色）；
  说明「余额只在礼遇内使用，暂不支持提现」；
- **设置**：外观（深色 / 浅色）、我的称呼（猜我是谁的答案，可用「/」写多个）、
  通知两个开关、数据（导出 JSON 路径 toast / 恢复演示数据，带确认）。

## 10. 引导（3 屏）

1. 送一份猜得到的心意 —— 挑一件小礼物，出一道只有 TA 答得上的题；
2. 契约让礼物有下文 —— 「收下就请我喝杯咖啡」，礼物是开头；
3. 不喜欢也不浪费 —— 四条要点：猜错不消失只是名字保密 / 7 天没拆全额退回送礼人 /
   换购 5% 折现 8% 先算给你看 / 余额只在礼遇内使用暂不支持提现。
