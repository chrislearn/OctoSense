# 02 · 流程与状态机

所有流程都在本机模拟：没有服务器、没有真实支付。「对方」的行为由演示模拟器驱动
（见 [05-data-model.md](05-data-model.md#演示模拟器)）。

## 1. 送礼流程（送礼人）

```
[挑礼页] 点一件礼物 / 顶栏「发起神秘送礼」
   │
   ▼
[送礼页] ─────────────────────────────────────────────────────────────
   已选礼物卡（名称 · 规格 · ¥价格 · 「换一件」回挑礼页）
   ⓪ 送给谁（仅自己可见的备注，从熟人里点选 / 不指定）
   ① 设置解密游戏  ○猜我是谁  ○专属私密问答  ○专属暗号  ○无条件直接领取
        猜我是谁 → 线索输入框（必填）；答案 = 我的称呼（设置里可改，可写多个别名）
        私密问答   → 问题（必填）+ 答案（必填）
        专属暗号   → 暗号（必填）+ 提示（选填）
   ② 绑定社交契约（可选）开关 → 预设四选一 / 自定义（≤24 字）
   ③ 寄语（选填，≤40 字）
   付款：☑ 优先用余额抵扣（余额 ¥x）→ 余额抵 ¥a，模拟支付 ¥b
   [生成神秘礼卡并发送（¥109）]
   │  校验失败：对应输入框下方红字，按钮不跳转
   ▼
[礼卡页] 礼卡预览（玩法 + 线索 + 口令，不含礼物与价格）
   [复制口令链接]  [保存礼卡图片]  [完成]
   │
   ▼
[礼盒 · 送出的] 新的一行：状态「待拆」
```

要点：

- 从熟人页某一行点「送礼」进来，⓪ 已选好这位；从回礼提示进来，⓪ 已选好对方，
  且顶部多一行「回礼预算：刚折现的 ¥100」。
- 离开送礼页（返回 / 切 Tab）即丢弃草稿，不做草稿箱 —— 这一页一分钟能填完。
- 支付是模拟的：余额不够的部分记一条「模拟支付」流水，不影响余额。

## 2. 收礼流程（收礼人）

```
[礼盒 · 收到的] 点一行 / 输入口令打开
   │
   ▼
① 解密页（状态 待拆 → 解谜中）
   「你收到一份神秘礼物」+ 玩法徽章
   TA 留下的线索 / 问题 / 暗号提示 卡片
   猜我是谁：6 个候选人芯片（真送礼人 + 熟人 + 通讯录，顺序打乱）或直接输入
   问答 / 暗号：一个输入框
   剩余 N 次机会   [提交答案]
   「猜错了礼物也不会消失哦」
   │  答对 → 揭晓（身份可见）
   │  答错 → 机会 -1，红字「不是 TA，再想想」；
   │  3 次用完 → 揭晓（身份保密：「一位神秘的朋友」）
   │  无条件领取 → 跳过本页，直接揭晓（身份可见）
   ▼
② 揭晓页（状态 已揭晓）
   「恭喜你答对了！这是 [林舟] 送你的礼物」/「礼物拆开了，TA 这次没透露名字」
   礼物卡：名称 · 规格 · 价值 ¥109 · 寄语
   附加契约卡：「收下表示答应：下周找时间回请我喝一杯咖啡」
   [✓ 满意，开心收下]            → ③a
   [↻ 不太喜欢？换购 / 折现余额]  → ③b
   │
   ├─▶ ③a 收下页
   │     有契约：☐ 我同意这个契约（必勾；同意即揭晓 TA 的名字）
   │     实物：收件人 / 手机号 / 地址（必填，演示只校验非空与手机号 11 位）
   │     电子券：无需地址，收下即显示券码
   │     [确认收下] → 状态 已收下；契约进入「契约 · 我答应的」；toast
   │     完成卡：「已收下」+ 券码或「商家将在 48 小时内发货（模拟）」+ [给 TA 回一份礼]
   │
   └─▶ ③b 换购 / 折现页
         分段：[换一份] [折成余额]
         折成余额：价值 ¥109 − 手续费 ¥9（8%）= 退回 ¥100 余额   [确认折现]
         换一份：抵扣额 ¥103（扣 5% 手续费 ¥6），下面是礼物列表，每行显示
                 「退回 ¥x」或「补 ¥y」；点一行 → 确认条 → [确认换购]
         完成卡：「已折现 ¥100」/「已换成 XXX」+ 回礼提示：
                「用刚才变现的余额，给 TA 回送一份『反击礼物』吧！」[去回礼] [以后再说]
```

要点：

- 契约在揭晓页就给看，收礼人在决定前就知道「收下意味着什么」；
- 换购 / 折现后契约**自动作废**，页面上写明；
- 身份保密时依然可以回礼：回礼的收件人是「那位神秘的朋友」，平台代转（演示里直接生成送出记录）。

## 3. 礼物状态机

```
            ┌──────── 撤回（仅送礼人，未打开前）───────▶ 已撤回
            │
  ┌──────┐  打开   ┌───────┐ 答对 / 用完机会 ┌──────┐ 收下 ┌──────┐
  │ 待拆 │───────▶│ 解谜中 │───────────────▶│已揭晓│─────▶│已收下│
  └──────┘        └───────┘                 └──────┘      └──────┘
     │  无条件领取：打开即揭晓 ───────────────▶  │  换购  ┌──────┐
     │                  │                        ├──────▶│已换购│
     └── 7 天未揭晓 ─────┴──▶ 已过期（全额退回送礼人）│  折现  ┌──────┐
                                                 └──────▶│已折现│
                                                          └──────┘
```

| 状态 | 收礼人看到 | 送礼人看到 | 终态 |
| --- | --- | --- | --- |
| 待拆 Sealed | 待拆 · 还剩 N 天 | 待拆 · 对方还没打开 | 否 |
| 解谜中 Opened | 解谜中 · 剩 N 次 | 解谜中 · 猜错 k 次 | 否 |
| 已揭晓 Revealed | 待你决定 | 已揭晓 · 等 TA 决定 | 否 |
| 已收下 Accepted | 已收下 | TA 收下了 | 是 |
| 已换购 Exchanged | 已换成 XXX | TA 换了一份更喜欢的 | 是 |
| 已折现 CashedOut | 已折现 ¥x | TA 折成了余额 | 是 |
| 已过期 Expired | 已过期，已退回给 TA | 已过期 · 已全额退回 | 是 |
| 已撤回 Withdrawn | （收礼人列表里不出现） | 已撤回 · 已全额退回 | 是 |

「已揭晓」不设超时：拆开之后不急着决定，礼物不会跑。

## 4. 契约状态机

契约只在**收下**那一刻生成，双方各一份视角：

```
 收下 ──▶ 待兑现 ──(我答应的：标记已兑现 / 答应我的：确认已兑现)──▶ 已兑现
            │
            └──(答应我的：「免了吧」)──▶ 已免除
```

- 期限：收下当天 + 7 天。过了期限显示「已逾期 N 天」，但仍可标记兑现（没有惩罚）；
- 「我答应的」一方不能自己取消 —— 答应了就是答应了；
- 「答应我的」一方可以「免了吧」—— 送礼人大方放过；
- 「提醒 TA」只弹 toast「已发一条温柔提醒（模拟）」，每条契约每天一次。

## 5. 资金流

金额一律以「分」为单位的整数计算，显示时转成 ¥x 或 ¥x.yz。

| 事件 | 余额变化 | 流水标题 |
| --- | --- | --- |
| 新人礼金（演示初始） | +¥20 | 新人礼金 |
| 送礼（余额抵扣部分 a） | −a | 送出 · 礼物名 |
| 送礼（模拟支付部分 b） | 0 | 模拟支付 ¥b（仅记录） |
| 撤回 / 过期退回 | +价格 | 退回 · 礼物名 |
| 折现 | +(价格 − 8% 手续费) | 折现 · 礼物名（手续费 ¥x） |
| 换购，新礼物更便宜 | +(抵扣额 − 新价格) | 换购退差 · 旧 → 新 |
| 换购，新礼物更贵 | −min(余额, 差价)，余下模拟支付 | 换购补差 · 旧 → 新 |
| 演示充值 | +¥50 | 充值（模拟） |

余额只进不出站：不可提现，只能用于送礼、换购补差。

## 6. 通知

两类，设置里各有开关，默认开：

1. **礼物等你拆**：收到的礼物处于待拆 / 解谜中，且离过期 ≤ 2 天：「有一份神秘礼物还没拆，2 天后会退回给 TA」；
2. **契约快到期**：我答应的契约待兑现，且离期限 ≤ 1 天：「你答应的『……』明天到期」。

每类每次运行最多弹一次；同时只显示一条。不做「TA 刚打开了你的礼卡」这类实时通知 ——
送礼人盯着进度会焦虑，进度去礼盒里看。
