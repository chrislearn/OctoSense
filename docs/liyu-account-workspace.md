# 我页公共工作区与数据页面（2026-09-27）

账号菜单原来属于 page_me 的子树。钱包、购物车、心愿单等 overlay 隐藏 page_me，因此把菜单一起隐藏；收到/送出的礼物菜单直接 set_tab(1)，进入礼盒。

现在 me_list 提升为公共 account_workspace 的左侧，所有业务页面放在右侧 workspace_pages。账号数据操作及其后续详情始终保留 tab=4，桌面（宽度≥820）保留菜单；窄屏先列表、再详情，返回按详情栈逐级退出。认证/引导隐藏整个业务工作区。其他主菜单仍使用自己的原页面，账号菜单不会出现在挑礼或礼盒中。

- 心愿单、购物车与订单、钱包与流水、送礼草稿统一右侧打开。心愿单的发布/编辑、商品详情等后续页面也保留桌面菜单。
- 收到的礼物用 page_account_received，送出的礼物用 page_account_sent；各有独立控件、列表、空态、刷新入口和角色 ID 映射。共用现有礼物 API 客户端和行样式，不使用 page_box、box_sent 或 box_rows 承载页面和点击状态。
- 所有账号菜单项统一单选；切换数据入口创建新的详情根，子详情可按来路返回。未保存编辑阻止切换并恢复原选中态。
- 账号菜单宽度从正文可用宽度中扣除，宫格/进度条按右侧宽度计算。礼卡/商品详情在右侧空间不足时改为纵向布局。
- 页面保留真实服务端权限和错误状态；不把断网伪造为空列表成功或本地送礼成功。

回归测试使用实际 WidgetRef 与 CheckBox/Button actions，覆盖412×892、820×700、1000×700、1280×800；六个数据入口、单选高亮、菜单/内容显隐、返回、独立收礼/送礼映射、未揭晓隐私文案、不修改礼盒状态、心愿编辑子页返回、非账号入口和未保存编辑保护。运行全目标 cargo check/test 与 clippy --all-targets --no-deps，外环在第二工作树复验。

控件树验证不是四尺寸真实截图或鼠标端到端验证；当前GUI工具没有识别开发版礼遇窗口，本次不声称完成真机视觉验收。已有同步客户端行为保持，网络延迟不属于本次导航修复。
